# 小小成功 · 成功日记

奶油色手账风的成功日记 PWA。彩色便签、小动物鼓掌、分类、搜索、珍藏和编辑，数据保存在当前浏览器中。

## 使用与安装

打开 https://debbie-anan.github.io/little-wins-diary/ 。

- iPhone：Safari 打开网址 → 分享 → 添加到主屏幕；如有“作为网页 App 打开”开关，请开启。
- Android：Chrome 打开网址 → 浏览器菜单 → 安装应用 / 添加到主屏幕。
- 首次联网打开后，可离线使用。

不同域名、设备与浏览器的数据不自动同步。清理网站数据会移除日记。仓库只包含应用代码，不包含用户记录。

## 本地运行

在仓库目录运行 `python -m http.server 8765`，然后打开 http://localhost:8765 。

GitHub Pages 从 main 分支根目录发布。
